# T45.8c neutral whole-cohort integration proposal

This is a Ben-routed Mac backend handoff. It makes `make dev` and `make dev-api`
select whole-repository indexing explicitly for the two existing neutral
repositories. It does not repair or claim focused service-query support.
`PHEBS_DEV_COHORT=focused` preserves the exact retained focused Search/evidence
demo; its service/relationship authority is unavailable. An absent selector
preserves legacy focused behavior for direct fixture environment bindings.
Explicit empty, padded, differently cased or unknown values refuse.

The historical `ui/receipts/t458b.json`, source bundles, catalogs and fixture
receipts remain exact. No manifest is synthesized and no authority guard is
removed. Whole mode refuses any configured T307 analysis unit. A posture change
on reused development data uses ordinary reindex/publication reconciliation;
the smoke uses a fresh private data root to avoid an invented historical claim.

## Prospective integration

`preregistration.json` freezes inputs, expected HEADs, required current services,
bounds, first-stop rules and historical bytes before the first candidate run.
`smoke.py` uses the real production `loadServeConfig` demo environment path. Its
minimal config has no connections, catalogs, analysis units or experimental
flags; the production binders must supply those. The only fixture cadence is
one-second Git polling, explicitly selected for this small run, with no product
default change. There is one server start, no rebuild/index generation command,
no restart/no-op extension, no browser or screenshot matrix and no signing.

The strict readiness predicates match the existing receipt cohort: exactly two
repositories at retained HEADs, exact done index/extraction jobs, no failed or
canceled resolver/caller jobs, both accepted services current in each five-row
catalog, and complete nonempty `orders-api` relationship authority. They also
pin the expected commits. Unavailable is pending only within the same deadline;
terminal jobs, crossed identities, unexpected repositories or malformed bodies
stop immediately. No response fixture seeds readiness.

After readiness, the finite checks are one anonymous service-search denial,
one authenticated T307 `orders-api` search with exact source/search authority,
one All code search proving the formerly excluded bulk sentinel is visible in
whole mode, and one actual relationship citation checked against its exact
page generation, projection, Git blob, content digest and committed byte span.
No zero-result absence, source accuracy, workflow safety or runtime claim follows.

Root must review the source and create an immutable checkpoint and outside
`phebs-t458c-execution-binding-v1` before any execution. The binding inventories
the exact product source, clean binary native VCS metadata, the six tool images,
owned/reused harness files and the preregistration digest. The source-only
binding check itself reads bounded local files and runs only three read-only
metadata commands (five seconds each); it precedes the product clock. Fresh
source/UI/helper images are prepared separately under root's serialized slot.

```sh
python3 spike/t458c/smoke.py \
  --binding /tmp/phebs-t458c-execution-binding-reviewed.json \
  --run-root /tmp/phebs-t458c-first \
  --out /tmp/phebs-t458c-first-result.json
```

The proposed single run is at most 180 seconds from private config preparation
through joined teardown/cleanup, with a 15-second cleanup reserve: startup 30s,
publication 90s, each complete HTTP/header/body read 5s, at most 400 calls and 2MiB
per body, 32MiB aggregate retained raw, one-second publication polls. These are
finite integration stops, not an operating SLO or scale claim. No process-tree
sampler is used and no transient peak, physical-headroom or Linux-capacity
result is claimed. The reused terminal receipt's wait4 RSS has its existing
limited scope; it is not a whole process-tree capacity measurement.

The server uses the reviewed T503 `OwnedServeSession`, total-wall HTTP helper
and terminal group-drain/stop logic. Its real PGID is retained across helper
completion. Forced cleanup is failure. The request timer joins per call; server
and group must be drained before removing data/config/logs. Graceful stop uses
at most eight seconds, reduced against the actual remaining global time while
reserving the helper's five-second reap plus two-second group-drain tail. Even
an already expired clock still attempts joined cleanup and remains a stopped
result; it cannot report a false 180-second pass. On failure only bounded private raw and a source-free
diagnostic survive after join; API key, config, derived data and server scratch
are removed. If ownership is not proven drained, custody is retained and the
result explicitly stops. Success removes the private root. A pre-existing root
or output refuses, and no silent retry or overwrite is allowed. Production
signing stays pending and is unrelated to this provisional demo integration.

## Steady-state cost review

The new production work is one closed environment lookup/selection at startup,
constant mode/unit checks and the same two catalog reads/digests. Ordinary serve
without demo bindings adds only the absent selector branch. No request, sync
tick, retry, publication or lifecycle work is added by the selector itself;
there is no new schema, cache, lock or child. Existing configured units are not
deleted or rewritten.

T307's retained input is 2,833 bundle bytes/nine regular files rather than seven
focused search files. Whole default deliberately indexes its external caller
and bulk file, uses the existing bounded source metadata census, whole/source/
search control publication and observation/service/relationship pipeline.
The whole index child replaces the focused child for T307; ordinary child,
concurrency, lock, cache invalidation and admission bounds remain those of the
existing pipeline. T323's 14-file whole cohort is unchanged. First startup or a
real whole/focused posture transition pays ordinary reindex/materialization;
unchanged startup/sync/no-op reuses the same exact generations. Runtime queries
use existing service-search/relationship readers and their existing bounds.
No new full-corpus read/hash is added to a query or periodic no-op.

Proposed controls (not executed while source is prepared): the focused Go
selectors `TestDevCohort*`, `TestLoadServeDevCohort`, `TestBindT307*` and
`TestBindT335*`; pure Python `python3 -m unittest -v test_smoke.py`; affected vet/
pinned lint and docs/glossary checks. The independent focused planning bypass
and whole-to-focused search-root retirement tests remain the intentional
runtime contract, not bugs to weaken. Broad command suites and historical
ceremonies are outside this leaf.

## Prospective peer-review corrections

Before the first native smoke, the startup health callback and ordinary API
reads now reserve from one shared 400-call counter before issuing each request.
Connection failures consume a call too. The receipt records the total and
bounded health metadata (status/body length or error type plus elapsed time),
without retaining healthy response bodies. This closes the earlier gap where
health probes were outside the recorded-read count; it changes no bound.

Both service inventories must also report the frozen source commit and exact
operator catalog kind/ID/version. The existing production binders already pin
those source/catalog inputs; this guard checks their actual HTTP projection.
Crossed commit, catalog ID/version and authority kind are refused in the pure
malformed-envelope controls for both repositories. No fixture bytes, supported
cohort or acceptance predicate is weakened.

The nine pure smoke controls passed once (unittest-reported 0.005 seconds),
including the shared health/API cap, failed health attempt and before-request
refusal checks. `checks/http-total-and-catalog-mocks.json` binds that supplemental
source/log record; earlier Go/race/vet/lint and eight-control logs remain exact.
The preregistration and protected input bytes remain unchanged. Root review and
a new immutable harness checkpoint still precede the single native smoke.
