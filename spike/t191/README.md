# T19.1 — Thrift protocol-pack validation spike

**Date:** 2026-07-25 · **Status:** COMPLETE · **Charter:** validate the
extraction rules for the future `thriftdecl` (thrift-contract) and `thriftgo`
(thrift-consumer) extractors against pinned real corpora before
productionizing (Epic 19, T19.2/T19.3). Spike code is throwaway; the binding
outputs are the decision table below and the executable gates in
`gates_test.go`.

Corpora are pinned in `corpus.lock.json` and cloned into `corpus/`
(gitignored). Run the gates with:

```
T191_FETCH=1 go test ./spike/t191/
```

An existing read-only checkout set can be reused without copying:

```
T191_CORPUS_ROOT=/absolute/path/to/corpus go test ./spike/t191/
```

Without the corpus present the gates skip, keeping the default offline suite
green (t111 precedent). An existing corpus runs only when its HEAD equals the
lock and its tracked bytes are clean; the untracked module fence is permitted.

(agent.thrift), 18 structs, 4 enums, 16 consts, 2 include statements
(agent → jaeger, zipkincore). **Zero** unions, exceptions, typedefs, `throws`

jaeger @ `b5b4f02`: imports jaeger-idl stubs cross-module, vendors none —
the honest-abstention showcase.

## Decision table (binding on T19.2/T19.3)

| # | Decision | Rationale / evidence |
|---|---|---|
| D1 | **Scope precedence:** last dot-segment of `namespace go`, then `namespace *`, else file basename. Operation object: `scope.Service/method`. | Thrift defines `*` as applying to every target language, including Go; ignoring it would create a declaration/generated-package mismatch. The real corpus has neither Go nor wildcard namespaces, so gate 2 proves its basename cases and the production synthetic suite pins explicit-Go/wildcard precedence. Gate 4 proves live joins on `/agent.Agent/emitBatch` and `/sampling.SamplingManager/getSamplingStrategy`. |
| D2 | **Implicit field IDs fail closed** as a file-level `THRIFT_EXTRACTION_GAP` (reason `implicit_field_id`). | Apache Thrift assigns negative wire IDs to implicit fields; emitting a guessed ID would fabricate wire identity. thriftrw parses them and flags `Field.IDUnset`, so detection is exact. Corpus count: 0. Mirrors protodecl's hard-fail on `extend`. |
| D3 | **Generated-file markers:** match both `// Code generated by Thrift Compiler` (0.13+) and `// Autogenerated by Thrift Compiler` (legacy). | Corpus exercises 0.14.1 and 0.19.0 (modern form); the legacy form has no HEAD-stable public corpus and is pinned by a synthetic fixture test. |
| D4 | **Go→wire method mapping:** wire universe from `processorMap["m"]` key literals; exact generated Go name from the client method whose `Call` carries literal `"m"`. | Apache publicizing changes underscores, common initialisms, and can vary by generator option. Reading the generated identifier plus wire literal avoids reimplementing it. Ambiguity emits canonical operation candidates, so downstream joins derive no Go name. Synthetic tests cover `get_url` → `GetURL` and `url` → `URL`. |
| D5 | **Consumer emissions:** `REGISTERS_THRIFT_SERVICE` from exact `New<Service>Processor` call sites; `CALLS_OPERATION` from selector calls (≥1 arg) whose method name maps to exactly one indexed service; ambiguity → `UNRESOLVED_THRIFT_CALL`. Client construction (`New<Service>Client*`) is deliberately not emitted. | Mirrors grpcgo's predicate set and unique-match-or-abstain posture. Exact-identifier matching excludes the `NewAgentClientUDP` wrapper (labeled negative). |
| D6 | **Measured heuristic noise:** handler-side same-name invocations are emitted as caller evidence (1 of 4 labeled emissions: `mock_agent.go`'s `GetSamplingStrategy`). | Syntactically indistinguishable without type checking, which the pure-reader boundary forbids. Same class of noise grpcgo accepts at heuristic tier; the Atlas already classifies these as name-bound caller evidence, never proven. |
| D7 | **Demo corpus (HEAD-bound):** jaeger-idl (declarations + stubs, active upstream), jaeger-client-go (archived, HEAD frozen — stubs + call sites in one repo, so joins fire under per-repo extraction), jaeger (cross-module abstention showcase). | Extraction is HEAD-bound and connections cannot pin refs; jaeger-client-go's archived status is the only found HEAD-stability guarantee for a stub+call-site public corpus. Gate 5 proves jaeger HEAD abstains. |
| D8 | **Typedef chains:** same-file resolution only, bounded chase (16) with cycle abstention; includes resolve to `unresolved` + import context, exactly like protodecl. | Corpus max chain length observed: 0 (no typedefs) — bound chosen conservatively, covered by synthetic fixtures in T19.2. |
| D9 | **Spike placement deviation:** spike lives in the main module (t111 precedent) and `go.uber.org/thriftrw v1.34.0` entered go.mod at T19.1 rather than T19.2 as originally planned. | t111 sets the in-module precedent; the pure-reader allowlist gate is unaffected until an extractor package imports the parser. |
