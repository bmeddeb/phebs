# DRAFT claim card: phebs.grpc.caller.comparison 1.0.0

**Status.** Unsigned draft for review. Production signing is pending the
existing unavailable key; this artifact grants no release activation.

**Claim and input.** Exact static protobuf/gRPC caller comparison over two
explicit endpoint selections and their authorized, current committed Caller
Map publications. The independent comparison claim requires the released
protobuf Caller Map recipe: proto-contract@4.0.0 and
grpc-caller@1.6.0-released.1, caller algorithm1.6.0, resolver packs
go-module@1.2.0 and grpc-generated-attribution@1.2.0. The service implementation
and response schema are compare_operation_callers@caller-comparison-v2.
Unsupported endpoint pairs and unavailable, stale, failed, partial, ambiguous
or overflow inputs retain their refusal/gap states. Empty results do not
prove caller absence.

**Measured qualification.** The exact bbb41b2c binary's 39.450236s Darwin-local
run independently matches five selected source sites, four supplied-unit
rows, four outside-pair negatives and five citation/attribution joins in a
frozen public-source population. Returned source tier is syntax/heuristic.
Unit rows cover old-only, new-only, both and unresolved. Three evaluator-
authored package units and one unavailable mapping test supplied attribution;
they are not runtime services or inferred ownership. The selected pair is
/helloworld.Greeter/SayHello versus /grpc.examples.echo.Echo/UnaryEcho.
This finite result establishes no generalized precision/recall or unseen-corpus
accuracy. The duplicate repository role adds concurrency evidence only.

**Surfaces and fences.** Ordinary verified disposable-key startup, authenticated
HTTP GET /api/compare_operation_callers, read-only MCP compare_operation_callers,
the /compare-callers UI, exact source citations,1280/390px keyboard interaction,
independent publication drift and dependency withdrawal pass. Two transitions
each retain eight concurrent exact-epoch responses and reject stale cursors
and changed-side citations. No experimental switch substitutes for admission.

**Bounds and cost.** Existing serving ceilings remain: a shared 50,000-record
two-side scan budget, 100rows and 100citation hydrations per page, four samples
per side, eight exact reads/two citation reads, eight cached indexes/eight
bindings and five-minute bindings. Identity payload admission is 128 MiB per
index plus overhead; cold index construction is serialized. No bound is
widened and no new request/sync/worker/cache/publication work is added.
The finite run uses two repositories and at most eight parallel comparison
requests under the retained plan. Observed post-readiness tree RSS peaks
at 283,901,952 bytes and sampled allocated data at 5,902,336 bytes, with at least
6,936,215,552 bytes sampled available physical memory. CPU and unsampled
startup/teardown/transient peaks are unmeasured. This is not a new SLO, hard
memory guarantee, production-sized operating envelope or Linux scale result.

**Non-claims.** No migration completion, API equivalence, runtime use,
deployment/owner truth, decommission safety, complete caller inventory,
cross-protocol comparison, field/Impact/Kafka/WIRE release, or universal
absence/accuracy claim. Historical failures stay exact. Generated managed
SCIP evidence receives no new admission.
