# T54.1 operation Impact source contract and oracle

This leaf freezes preparation for one endpoint-qualified, paged protobuf
operation report. It grants no composed-quality, operating or production
result. The parent records the architectural decision in PLAN.

The proposed view wraps the existing exact `CallerMapService.List` response.
That response already resolves its declaration from the admitted caller
resolver publication. Its optional legacy coverage certificate is absent;
the report preserves the exact generation, source/candidate census and scope
instead of manufacturing a certificate. It adds no classifier, second Atlas
query, durable report store, pin or archive schema.

`contract.json` specifies the claim, current gaps, dependencies, API/MCP/UI
shape, uncertainty, numeric ceilings, cost and minimum T54.2 code map.
`oracle.json` preregisters five RPCs, nine application source sites, 36
wrong-operation exclusions and two scoped filtered-empty queries. Five rows
have supplied package units and four retain unavailable attribution. These
are nine distinct source sites; transport/paging repeats add no truth samples.

`input-binding.json` binds the unchanged Apache-2.0 gRPC source, evaluator
module/snapshots, committed canonical SCIP and nineteen-file Git census.
`base.bundle` is the exact existing T503 input bundle, copied without Git,
indexing, fetching or source edits. Upstream provenance and evaluator commits
remain distinct. T503's source-reviewed coordinates are reused as input
truth, with a new directly reviewed composition oracle; its product results
and component metrics do not qualify Impact. T491 contributes only its
applicable whole-RPC declaration span convention. T492 is not consumed.

`qualification-plan.json` separates direct source quality from one finite
Darwin-local operating/read/UI/publication proof. Independent source-only
review and an immutable checkpoint precede every report/candidate execution.
Only the verified Caller Map recipe and this view's own eventual claim are
release dependencies. Field/change/implementation/WIRE/matching/saved shapes
remain explicitly unavailable. Production signing awaits the existing key.

The only execution in this leaf reads already licensed public bytes:

```sh
python3 spike/t541/check_source.py --source-root <bound existing clone> --out <new receipt>
python3 -m unittest discover -s spike/t541 -p 'test_*.py'
```

The checker imports no product code and accepts no predictions. It verifies
hashes, source slices, generated wire literals, lineages and finite oracle
membership. It is neither an extractor nor an Impact candidate scorer.
