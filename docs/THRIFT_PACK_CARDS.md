# Thrift protocol-pack cards

Completed instances of the [evidence-pack card template](./EVIDENCE_PACK_CARD.md)
for the Epic 19 and Epic 22 Thrift packs. All packs are
**experimental-dark**: the release
invariant's blank-field prohibitions bind at `released` status, which neither
pack holds or requests. The PackRelease binding machinery remains design-only
(see [PACK_MANIFEST.md](./PACK_MANIFEST.md)); fields that depend on it say so
explicitly rather than simulating it.

---

## Pack: Thrift declared contracts

| Field | Value |
|---|---|
| Pack ID | `phebs.thrift.contract` |
| Status | `experimental-dark` |
| Predicate(s) | `DECLARES_SERVICE, DECLARES_OPERATION, DECLARES_MESSAGE, DECLARES_FIELD, THRIFT_EXTRACTION_GAP` |
| Language/framework | Thrift IDL (language-neutral source); parsed by `go.uber.org/thriftrw` v1.34.0 `idl`/`ast` |
| Pack version | `1.0.0` (`thrift-contract` extractor) |
| Extractor artifact | in-tree `internal/extract/extractors/thriftdecl`; no separate binary — the phebs release binary digest governs |
| Schema version | atom `t19-v1`; details `thrift-service-detail-v1`, `thrift-operation-detail-v1`, `thrift-message-detail-v1`, `thrift-field-detail-v1`, `thrift-gap-detail-v1` |
| Release binding | none — experimental-dark; PackRelease machinery is design-only |
| Owner | Ben Meddeb |
| Independent validation owner | none — single-operator project; see validation section |
| Last measured | 2026-07-25 (T19.1 spike gates at pinned corpora) |
| Validation expires/review due | re-run `spike/t191` gates on any parser upgrade, rule change, or corpus re-pin |
| Exception authority | operator (Ben Meddeb); the pack itself grants no exceptions |
| Current decision | dark — enabled only by `experimental.provisional_thrift_extraction` |

**Claim.** For each `.thrift` file readable at the indexed commit, the pack
asserts the services, operations (`scope.Service/method`), struct/union/
exception shapes, and numbered fields that file declares, with exact
declaration-start-line source locators, tier `exact`, and file-scoped
provisional lineage (`provisional_repo_path_v1`). Operation request/response
shapes are the wire-implicit argument/result structs (field `0` success,
`throws` as result fields, no result struct for `oneway`), emitted as
synthetic same-file messages and marked `synthetic`.

**Non-claims.** No cross-file or cross-repository identity: include-qualified
types stay `unresolved` with include context; lineage equality across repos is
never asserted. No runtime behavior, no absence claims, no accuracy
percentage (GATE2-V2 remains `NOT_ESTABLISHED`). No wire-compatibility
verdicts — Buf checking is protobuf-only and has no Thrift engine. Inherited
operations of `extends` services are not expanded (the parent name is
recorded in service detail).

**Incomplete analysis representation.** Files with implicit or out-of-range
field identifiers produce exactly one tier-`unresolved`
`THRIFT_EXTRACTION_GAP` assertion (`implicit_field_id` / `invalid_field_id`)
and no shape claims — Thrift assigns negative wire identifiers implicitly,
and emitting a guess would fabricate identity. Parse, read, complexity-bound,
and publication failures abort the whole staged run, leaving prior published
facts intact. Same-file typedef chains are chased at most 16 hops; nested
containers beyond one level abstain (`NESTED_CONTAINER_SHAPE`).

**Validation.** T19.1 executable rule gates (`spike/t191`, corpora pinned in
`corpus.lock.json`): 100% parse rate over jaeger-idl; scope precedence
(`namespace go` last segment, else file basename for the constructs present)
reproduced by every generated package in the same corpus; wildcard namespace
precedence is a synthetic regression because the corpus has none. Live gates
first verify the locked HEAD and clean tracked bytes. Cross-corpus
operation-object joins and byte-identical double extraction are pinned. These
are rule-validation gates, not accuracy measurements.

**Operating envelope.** 4 MiB / 500k tokens / 128 nesting levels per source
file; 64 include paths / 4 KiB include context; worker bounds are 12,500
facts in deterministic 256-fact chunks and a 15-minute run. The store's
whole-run admission is 25,000 association-plus-assertion rows; each staging
call remains capped at 10,000 rows of one kind.
`.thrift` symlinks fail the corpus walk closed.

## Pack: Thrift Go consumers

| Field | Value |
|---|---|
| Pack ID | `phebs.thrift.consumer.go` |
| Status | `experimental-dark` |
| Predicate(s) | `REGISTERS_THRIFT_SERVICE, CALLS_OPERATION, UNRESOLVED_THRIFT_CALL, UNRESOLVED_THRIFT_REGISTRATION, THRIFT_EXTRACTION_GAP` |
| Language/framework | Go consumers of Apache Thrift compiler Go output (modern `Code generated by Thrift Compiler` and legacy `Autogenerated by Thrift Compiler` headers; corpus-validated on 0.14.1 and 0.19.0) |
| Pack version | `1.1.0` (`thrift-consumer` extractor) |
| Extractor artifact | in-tree `internal/extract/extractors/thriftgo`; no separate binary — the phebs release binary digest governs |
| Schema version | atom `t19-v1`; details `thriftgo-register-detail-v1`, `thriftgo-call-detail-v1`, `thriftgo-call-ambiguity-v1`, `thriftgo-register-ambiguity-v1`, `thriftgo-gap-detail-v1` |
| Release binding | none — experimental-dark; PackRelease machinery is design-only |
| Owner | Ben Meddeb |
| Independent validation owner | none — single-operator project; see validation section |
| Last measured | 2026-07-25 (T19.1 spike gates at pinned corpora) |
| Validation expires/review due | re-run `spike/t191` gates on any rule change, marker addition, or corpus re-pin |
| Exception authority | operator (Ben Meddeb); the pack itself grants no exceptions |
| Current decision | dark — enabled only by `experimental.provisional_thrift_extraction` |

**Claim.** Within one repository, the pack asserts handler registrations
(`New<Service>Processor` call sites, tier `derived` — name-bound to a
same-repo generated constructor) and client call sites (tier `heuristic` —
the exact generated Go method name is unique across the repository's stub
index). The wire method universe comes from `processorMap` key literals and
each Go identifier is anchored by that generated client's
`Call(..., "wire", ...)` literal. Operation objects are
`/scope.Service/method` with scope taken from the generated package name,
joining the declaration pack's D1 identity by string equality.

**Non-claims.** No cross-repository or cross-module resolution: a repository
that imports generated stubs instead of vendoring them produces no consumer
evidence (honest abstention — spike gate 5). Lineage equality with
declarations is never asserted; the `proven` classification stays
structurally unreachable, exactly as for the gRPC pack. Client construction
(`New<Service>Client*`) is deliberately not evidence. No runtime claims, no
absence claims, no accuracy percentage.

**Incomplete analysis representation.** Ambiguous constructor or method
names abstain as `UNRESOLVED_THRIFT_REGISTRATION` / `UNRESOLVED_THRIFT_CALL`
with candidate counts; call ambiguity emits one canonical operation candidate
per possible target so downstream queries reproduce no compiler naming rule.
Oversized and unparseable files produce
`THRIFT_EXTRACTION_GAP` (`source_too_large` / `parse_error`); empty files are
complete coverage. Underscores, common initialisms, and generator options do
not require a local publicizing approximation.

**Validation.** T19.1 spike gate 3: zero false name resolutions on the
hand-labeled jaeger-client-go sample, including the exact-identifier negative
(`NewAgentClientUDP`), with one measured handler-side semantic-noise emission
(D6). Synthetic regressions cover underscore and initialism publicizing.
Persisted-path parity: `TestThriftPackEndToEnd` drives both packs through the
real worker and store and requires the operation-object join. These are
rule-validation gates, not accuracy measurements.

**Operating envelope.** 4 MiB per Go source file; generated files are read
once for indexing. Non-generated Go files are read once during header
recognition and again during source-backed scanning (within the worker's read
budget); worker bounds are 12,500 facts in deterministic 256-fact chunks and
15 minutes. The store admits 25,000 association-plus-assertion rows per run;
each staging call remains capped at 10,000 rows of one kind.

## Pack: Apache Thrift field references

| Field | Value |
|---|---|
| Pack ID | `phebs.thrift.field.apache` |
| Status | `experimental-dark` |
| Predicate(s) | `REFERENCES_THRIFT_FIELD` |
| Language/framework | Go generated by Apache Thrift Compiler (validated modern and legacy header eras), joined through a repository-root committed SCIP index |
| Pack version | Apache rules `1.0.0`; `scip-thrift-field` extractor `1.1.0` |
| Extractor artifact | in-tree `internal/extract/extractors/thriftfield`; no separate binary — the phebs release binary digest governs |
| Schema version | atom `t22-v1`; detail `thrift-field-reference-detail-v1` |
| Release binding | none — experimental-dark; PackRelease machinery is design-only |
| Owner | Ben Meddeb |
| Independent validation owner | none — single-operator project; see validation section |
| Last measured | 2026-07-26 (T22.1 pinned-corpus rule gates; T22.3 synthetic production regressions) |
| Validation expires/review due | re-run `spike/t221` and T22.3 gates on any marker, struct-tag, symbol-binding, or generator-version rule change |
| Exception authority | operator (Ben Meddeb); the pack itself grants no exceptions |
| Current decision | dark — enabled only by `experimental.provisional_thrift_field_extraction` |

**Claim.** A file is eligible only when one validated Apache Thrift compiler
header appears as an anchored comment-line prefix in its first 4 KiB and the
parsed Go contains at least one valid `thrift:"name,ID[,flags]"` struct tag.
The generated package, enclosing struct, tag name, and field ID derive
`scope.Message#ID`; the exact tagged identifier span must be the unique SCIP
definition under that same enclosing type. References cite exact immutable
source spans and preserve `write > read > test > generated > unknown`
classification. Field `0` is first-class.

**Tier and source binding.** Apache generated Go embeds no IDL bytes, digest,
source path, or independently verifiable declaration identity. Every row is
therefore tier `derived`, `generator=apache`, and `source_binding=none`.
Neither a matching declaration in another repository nor coexistence with a
thriftrw package promotes it.

**Non-claims.** The package-derived scope is not an IDL namespace proof and
`contract_scip_package_v1` is not equality with the declaration pack's
file-scoped provisional lineage. A direct reference does not prove semantic
use or runtime traffic. The pack makes no completeness, absence, or
measured-accuracy claim. T22.3 adds ingestion only; HTTP, MCP, proof, report,
and UI support remain T22.4/T22.5 work.

**Incomplete analysis representation.** Header lookalikes, files without a
valid tag, definition spans on untagged fields, wrong enclosing SCIP types,
duplicate definitions, and duplicate `(message, field ID)` claims abstain.
Malformed candidate Go, invalid tags or IDs, unusable package scope, and
over-limit candidates abort the staged run so prior published evidence stays
visible.

**Validation.** T22.1 G4/G5 validate ten tagged structures across five Apache
generated files, both compiler-header eras, IDs against the separate pinned
IDL corpus, zero embedded ThriftModule identities, and zero false-eligible
handwritten files. T22.3 production regressions cover default/required/
optional tag shapes, field `0`, package-derived scope, wrong-owner and
untagged abstentions, malformed candidates, exact spans, role classification,
duplicate identity refusal, and exact-thriftrw/derived-Apache coexistence in
one repository. These are rule gates, not an accuracy measurement.

**Operating envelope.** The shared reader admits a 32 MiB root index, 50,000
documents, 500,000 occurrences, 8 KiB per symbol, and 4 MiB per generated
candidate. Only the same immutable repository commit's root `index.scip` and
referenced regular blobs are read; phebs never runs or downloads an indexer.
Worker bounds are 12,500 facts in deterministic 256-fact chunks and 15
minutes. The store admits 25,000 association-plus-assertion rows per run; each
staging call remains capped at 10,000 rows of one kind.

## Pack: thriftrw field references

| Field | Value |
|---|---|
| Pack ID | `phebs.thrift.field.thriftrw` |
| Status | `experimental-dark` |
| Predicate(s) | `REFERENCES_THRIFT_FIELD` |
| Language/framework | Go generated by `go.uber.org/thriftrw`, joined through a repository-root committed SCIP index |
| Pack version | thriftrw rules `1.0.0`; carried unchanged by `scip-thrift-field` extractor `1.1.0` |
| Extractor artifact | in-tree `internal/extract/extractors/thriftfield`; no separate binary — the phebs release binary digest governs |
| Schema version | atom `t22-v1`; detail `thrift-field-reference-detail-v1` |
| Release binding | none — experimental-dark; PackRelease machinery is design-only |
| Owner | Ben Meddeb |
| Independent validation owner | none — single-operator project; see validation section |
| Last measured | 2026-07-26 (T22.1 pinned-corpus rule gates; T22.2 committed real-indexer fixture) |
| Validation expires/review due | re-run `spike/t221` and the T22.2 fixture gates on any parser, generator-recognition, SCIP-indexer, or identity-rule change |
| Exception authority | operator (Ben Meddeb); the pack itself grants no exceptions |
| Current decision | dark — enabled only by `experimental.provisional_thrift_field_extraction` |

**Claim.** A reference is emitted only after a three-way same-file binding:
the generated Go file contains an exact `go.uber.org/thriftrw/thriftreflect`
`ThriftModule`; `SHA1(Raw)` matches its descriptor; the Raw IDL field and
generated struct-field order agree with the `wire.Field{ID: ...}` literals;
and an exact SCIP definition range names that generated field or accessor.
Non-definition occurrences of the bound symbol cite exact byte and line spans.
Objects are `scope.Message#field-ID` for IDs 0 through 32,767. Tier is `exact`
because the module digest binds the embedded IDL bytes; current field spelling
and dependency version remain detail, while
`contract_scip_package_v1` lineage excludes both so a rename with the same
message and field ID preserves identity. Classification precedence is
`write > read > test > generated > unknown`.

**Non-claims.** Apache Thrift compiler output is governed by the separate
derived-evidence card above; it never inherits this card's exact tier.
The lineage is package identity, not a claim that this pack joins the
file-scoped `thrift-contract` declaration lineage. A direct reference is not
proof that a returned field was semantically read, nor evidence of runtime
traffic. The pack makes no completeness, absence, or measured-accuracy claim.
T22.2 adds no HTTP, MCP, proof, report, or UI query surface; those remain
T22.4/T22.5 work.

**Incomplete analysis representation.** A missing root `index.scip` publishes
stable `scip-index-absent` coverage with no facts. Local symbols, empty or
invalid reference ranges, ineligible documents, non-digest-bound modules,
duplicate SCIP definitions, duplicate `(message, field ID)` declarations,
and joins that disagree abstain instead of guessing. Malformed or over-limit
indexes and malformed eligible generated candidates abort the staged run so
the prior publication remains intact.

**Validation.** T22.1 gates pin the descriptor digest join across all 12
cadence thriftrw modules, agreement across 267 generated structures, field
`0`, exact SCIP range/type matching, adversarial abstentions, lineage
stability, and the 3,455,648-byte largest generated candidate. T22.2 adds
table-driven production fixtures for exact spans and classifications,
rename-stable identity, duplicate-definition and duplicate-field-ID
abstention, field `0`, all SCIP position encodings, missing/malformed indexes,
two-run byte determinism, and real worker staged-to-published behavior. A
small committed index generated by pinned `scip-go` v0.2.7 independently
confirms production accessor symbol/range shapes. These are rule and
integration gates, not an accuracy measurement. T22.3's coexistence fixture
additionally pins that admitting Apache rows does not change thriftrw tier,
identity, or detail.

**Operating envelope.** T22.1 did not measure the protobuf pack's inherited
64 MiB / 100,000-document / 1,000,000-occurrence scale envelope, so this pack
narrows admission to 32 MiB per root index, 50,000 documents, 500,000
occurrences, 8 KiB per SCIP symbol, and 4 MiB per generated candidate. The
trusted corpus admits only the same repository commit's regular root
`index.scip`; no indexer is run or downloaded by phebs. Worker bounds are
12,500 facts in deterministic 256-fact chunks and 15 minutes. The store admits
25,000 association-plus-assertion rows per run; each staging call remains
capped at 10,000 rows of one kind.
